# Banking System Console

## Intern Information
- **Intern ID:** CITS1043

## Overview
A simple console-based banking system built in Java using Eclipse IDE.  
Features:
- Create account
- Deposit money
- Withdraw money
- Display account details

## How to Run
1. Clone the repository.
2. Import into Eclipse IDE.
3. Run `BankingApp.java`.

## Technologies
- Java
- Eclipse IDE
- HashMap for storage
